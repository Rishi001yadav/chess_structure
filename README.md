# ♟️ Chess Board — HTML & CSS

A simple and clean **Chess Board structure** created using **HTML5 and CSS3**. This project demonstrates how HTML can be used to create the basic structure of a chessboard and CSS can be used to style, position, and arrange the individual squares.

## ✨ Features

* ♟️ 8 × 8 chessboard layout
* ⬛⬜ Alternating black and white squares
* 🎨 Styled completely using CSS
* 📐 Structured layout using HTML
* 💻 Built without JavaScript
* 🌱 Beginner-friendly project

## 🛠️ Technologies & Tools

* **HTML5** — Used to create the structure of the chessboard
* **CSS3** — Used for styling, positioning, sizing, and layout
* **VS Code / Text Editor** — Used for writing and editing the code
* **Web Browser** — Used to preview and test the project

## 🎯 Purpose

The main purpose of this project is to practice creating **structured layouts using HTML** and styling them using **CSS**.

Through this project, I practiced:

* HTML elements and structure
* CSS properties
* Width and height
* Positioning and alignment
* Layout techniques
* Creating repeated visual patterns

## 🚫 Project Scope

This project focuses only on the **visual structure of a chessboard**.

It does **not** include:

* ❌ Chess game functionality
* ❌ Piece movement
* ❌ Move validation
* ❌ Game logic
* ❌ JavaScript functionality
